#  Student Performance Prediction System

## Overview
This project predicts whether a student will pass or fail using Machine Learning.

It is built as a complete end-to-end system:
- Data Analysis
- Feature Engineering
- Model Training
- API (FastAPI)
- UI (Streamlit)

---

##  Tech Stack
- Python
- Scikit-learn
- FastAPI
- Streamlit

---

## Architecture

UI (Streamlit) → API (FastAPI) → ML Model

---

## How to Run

### 1. Install dependencies
pip install -r requirements.txt

### 2. Run API
uvicorn app.api:app --reload

### 3. Run UI
streamlit run app/ui.py
